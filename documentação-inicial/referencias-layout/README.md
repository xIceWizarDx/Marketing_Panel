## 📁 publer/ *(aguardando)*

O que mais interessa, em ordem:
1. **O compositor com 2+ redes selecionadas** ← a peça que falta
2. **A personalização por rede** (quando customiza uma delas)
3. A pré-visualização por rede *(é o forte deles)*
4. Lista de publicações com status real
5. Qualquer tela no celular

essas a gente desenha do zero.
